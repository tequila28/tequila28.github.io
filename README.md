# JY Feng Academic Homepage

This is a lightweight static academic homepage for GitHub Pages.

## Deploy to GitHub Pages

Recommended repository name:

```text
tequila28.github.io
```

After creating the repository on GitHub, run:

```bash
git init
git add index.html styles.css .nojekyll README.md
git commit -m "Initial academic homepage"
git branch -M main
git remote add origin https://github.com/tequila28/tequila28.github.io.git
git push -u origin main
```

The site will be available at:

```text
https://tequila28.github.io/
```

If GitHub Pages does not publish automatically, open the repository settings:

```text
Settings -> Pages -> Build and deployment -> Source: Deploy from a branch -> Branch: main / root
```
